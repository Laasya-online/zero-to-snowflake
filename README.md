# Zero-to-Snowflake
This project is a complete, practical walkthrough of Snowflake concepts using a single SQL workspace.  

---
## What This Project Covers

1. Setup
2. Virtual warehouses
3. Transformation
4. Sample data line
5. External stage ingestion
6. Semi-structured data
7. Dynamic tables
8. Build out the pipeline
9. AISQL functions
10. Roles and access control
11. Snowflake marketplace data
12. Streamlit application
